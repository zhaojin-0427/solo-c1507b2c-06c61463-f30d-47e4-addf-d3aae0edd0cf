# 轮系配齿台（Gear Train Workbench）

供钟表维修与机械模型制作推演复合齿轮列的本地工具：在 SVG 画布上放轴、装齿轮、
连啮合/同轴，实时传播转速与方向，计算总传动比、各轴转数与整列恢复初始啮合的循环；
并在锁定部分轴位/齿轮后按目标传动比搜索替换齿数与模数组合。

另含**行星轮系推演**：独立编辑器配置太阳轮/内齿圈/2～6 个相同行星轮/行星架的
模数、齿数与固定-输入-输出角色，按 Willis 关系求解各构件转速与方向，检查
`z圈 = z太阳 + 2z行星`、均布装配条件、行星轮净距与同轴尺寸冲突；可按目标传动比、
齿数范围、行星数量与外径上限搜索可装配组合，选定后接入现有轴参与整体传动比计算。

## 运行

```bash
pip install flask
python app.py
```

浏览器打开 <http://127.0.0.1:5000> 。数据保存在同目录 `geartrain.db`（SQLite），
画布自动保存；方案（备选）与基线也存库。

## 建模规则

- 齿轮参数：齿数 z、模数 m、压力角（默认 20°）、内齿圈标记；节圆半径 r′ = m·z/2。
- 外啮合中心距 = m(z₁+z₂)/2，相邻轴转向相反；
  内啮合中心距 = m|z圈−z轮|/2，转向相同。
- 同一根轴上的所有齿轮同转速；**同轴关系**表示两根同心安装但转速独立的轴，
  建立时未锁定轴会自动吸附同心。
- 转速用精确分数（Python `fractions` / 前端 BigInt）传播，闭合轮系两条路径
  推得的转速会被比对：符号相反报「转向矛盾」，同号不等报「传动比矛盾」。
- 复位循环 L：所有齿轮在输入轴转过 L 转后同时回到初始齿相位，
  即对每个 z·n 求分母的 LCM。

## 行星轮系

- 顶部工具切到「行星级」后点画布空白处放置（或「行星轮系」页点「＋ 新行星级」），
  在独立编辑器中配置模数 m、zS/zP/zR、行星轮数 2～6 与初相位。
- 固定件/输入件/输出件分别指定太阳轮 s、内齿圈 r、行星架 c，三种典型级比：
  - 齿圈固定、太阳输入、架输出：i = zS/(zS+zR)（减速）；
  - 太阳固定、架输入、齿圈输出：i = (zS+zR)/zR；
  - 架固定、太阳输入、齿圈输出：i = −zS/zR（反向）。
- 装配检查：`z圈 = z太阳 + 2z行星`、均布条件 `(zS+zR)/n` 为整数、
  相邻行星顶圆净距 > 0（< 0.15m 告警）、太阳齿顶不越入齿圈齿顶、
  接入轴上的外齿轮不超出齿圈内腔。
- SVG 同时绘制节圆、行星轴轨迹圆（蓝虚线）与当前相位；拖动「输入转角」滑块或
  连续播放时，太阳自转、行星轮自转与绕日公转（行星架严格作为行星轮的父坐标系，
  保证同相同步）、行星架转动由统一的输入转角按精确转速比驱动。
- 「接入现有轴」可把 s/r/c 与真实轴锁定为同速，整体传动比与复位循环自动重算
  （行星轮绝对自转 n_p = n_c − (zS/zP)(n_s − n_c)，其齿数也计入复位循环）。
  接入后全局输入保持在原齿轮列的输入轴，整体从该轴串到行星级输出端
  （如原列 1/9 × 级比 1/4 = 1/36）；只有独立行星级才会自动充当全局动力源。
- 复位循环同时要求：各齿轮 z·n·L 为整数齿距、行星轮绝对自转 zP·n_p·L 为整数、
  且均布行星轴位恢复 n·n_c·L 为整数（行星架回到 n 重槽位）。因此默认
  24/24/72、n=3、齿圈固定级并非输入 1 转复位，而是 **4 转**（行星架整转一圈）。
- 行星级配齿搜索：给定目标级比、齿数范围、行星数与外径上限，后端枚举 zS/zP
  （zR 由几何关系确定），按**比值误差 → 外径 → 重复啮合周期 → 最大齿数**排序；
  候选可蓝色虚线叠加预览（含播放检查）、采用到当前行星级，或直接建成新行星级。
  与普通配齿候选一样可在方案库中另存，并与绿色基线对照。

## 齿对接触周期与装配相位

齿序由本机 Python 后端（`contact.py` + `/api/teeth`、`/api/teeth-assembly`）精确计算，
零号齿方向、关注齿、磨损/崩角/修补标记与整齿装配偏移都随项目 state 写入 SQLite。

- **齿轮属性**：每只普通齿轮可设置零号齿方向（θ=0 时 0 号齿中心线的全局方向角）、
  整齿装配偏移（齿距数）与「带键锁定」；属性面板提供点齿环，可把任意齿标为
  关注齿或磨损/崩角/修补齿（外啮合、内啮合均可）。
- **观察窗**：「齿对/相位」页顶部限定观察的输入转数。
- **齿对展开**：系统以输入轴为根沿传动方向 BFS，逐次展开在节点处进入啮合的齿对
  （节点固定不动：主动轮正向转过一个齿距时，抵达节点的是上一号齿，故主动齿号递减；
  外啮合从动轮反转、齿号递增，内啮合同向、齿号递减；主动轴反转时整体反号），
  给出每处啮合的可到达齿对数 `zA·zB/gcd(zA,zB)`、齿对重复周期（事件数与输入转数）、
  观察窗内各齿对相遇次数；`gcd>1` 时明确提示**长期只在固定子集循环**（其余齿对永不接触）。
  描述一律按传动方向（A=主动、B=从动）输出，与啮合边 gearA/gearB 的存储顺序无关，
  矩阵行恒为主动齿、列恒为从动齿。
- **接触矩阵**：行=主动齿、列=从动齿，颜色越深窗内相遇越多；点格跳到该齿对的
  首次相遇输入角，播放/拖动时当前齿对格子同步描边，画布上以红/橙弧高亮当前啮合齿号。
- **关注齿相遇**：列出两侧关注齿彼此相遇的输入角（度与精确分数转）与窗内次数；
  标记齿（磨损/崩角/修补）进入啮合的时刻同样可一键跳转回放。
- **装配枚举**：带键齿轮相位锁定后，枚举其余可达齿轮 ±N 齿距的整齿偏移组合，
  按 **关注齿窗内相遇越少 → 首次相遇越晚（不相遇最优）→ 相位改动越小** 排序；
  候选可「叠加当前装配」预览（画布与面板按候选齿序重算），「采纳并另存方案」会把
  偏移写入齿轮并立即另存到方案库。

## 回程间隙工况

「回程间隙」页以**一次轮系换向**为独立工况对象（`backlash.py` +
`/api/backlash/*`，版本存 SQLite 表 `backlash_cases`，不改写原轮系方案）。

- **草稿与过期**：点「从项目快照建立草稿」把当前轮系快照为工况；每处啮合记录
  法向齿侧间隙 jn（空程分析始终使用已录入值；「锁定实测」仅限制搜索是否调整该级）、
  中心距公差、偏心量与初始贴合齿面（工作面/非工作面），并指定输入轴、观察轴与
  换向角；间隙等级下拉可快捷填入 jn = k·m。源轮系的齿轮（z/m/x/压力角）或轴位
  一旦变化，面板顶部即显示**过期**提示，可一键刷新快照（保留仍存在啮合的参数）。
- **空程折算**：圆周侧隙 jt = jn/cosα，从动轴自由摆角 φ = jt/r从动，
  逐级折算到观察轴（×|n观察/n从动|）；中心距公差与偏心量把 jn 展宽
  ±2(tol+e)·sinα，给出观察轴**最小/最大空程**与**每级贡献**。初始贴合
  非工作面的级换向不换面（贡献 0）。
- **分支/闭环**：输入→观察轴的每条简单路径给出滞后区间 [Φmin, Φmax]，
  各路径求交得**相容区间**；无交集时按路径对称差**定位冲突啮合**（红色卡片标出）。
  每条路径都有完整的逐级数据，面板在多条路径时给出切换按钮，逐级明细与
  换向动画按所选路径展开。
- **换向动画**：拖动换向角滑块或点「▶ 换向」，SVG 逐级显示齿面离开工作面、
  越过间隙、贴上非工作面再带动后级（主动/从动轮刻线按精确转速比转动，
  时间轴标出各级换面角与换向角上限）；侧栏同步列出各级接触面切换的输入角，
  当前级高亮。
- **组合搜索**：未锁定实测的啮合在中心距调整量 ±Δa、变位系数和 xΣ 与
  间隙等级（消隙/精密/标准/宽松/大间隙，jn = k·m）范围内枚举，
  按 **最坏空程 → 冲突数 → 改动量** 排序。选中方案可「叠加基线」
  （与草稿、任选已存版本做空程区间与每级贡献对照图）并「另存版本」
  （同名工况版本号递增），全程不改动画布上的轮系方案。

## 载荷工况

「载荷工况」页以**一次轮系受载**为独立工况对象（`loadcase.py` +
`/api/loadcase/*`，版本存 SQLite 表 `load_cases`，不改写原轮系方案）。

- **草稿与过期**：点「从项目快照建立草稿」把当前轮系快照为工况，记录输入轴、
  输入转矩（N·m）、输入转速（rpm）与持续时间（h）；为每处啮合填**效率 η** 与
  **载荷系数 KA**（η 可填 0：该级不输出功率，本级输出与后续功率/转矩/啮合力
  全部归零、输入功率整级计为损耗；但输入轴传入本级的转矩与齿面力仍按输入功率
  正常计算，两齿受力等大反向，故输入轴轴承反力不被低估），为分流轴指定各分支**载荷比例**（默认等分），并在每根
  轴的轴向标尺上布置齿轮**安装面**、两处**轴承**；每个轴承都可编辑**位置 x** 与
  **径向额定载荷 Cr**（输入框与 SVG 拖动双向同步，参与分析、布置搜索与版本保存）。
  传播始终从工况实际选中的输入轴沿其所属连通分量 BFS，与项目全局输入轴无关；
  源轮系齿轮（z/m/x/压力角/**内啮合标记**）或轴位变化时，面板顶部显示**过期**
  提示；已存版本只被标记为过期，不自动重算，可一键刷新快照（保留仍存在啮合/轴
  与轴承的参数）。
- **功率与转矩传播**：复用快照运动学（传动比与外/内啮合方向），按 BFS 深度把
  啮合从输入端定向；分流按给定比例分配功率、汇流相加；每级损失 P到从动=P级·η，
  T=P/ω。切向力 Ft=T/r 再乘 KA，径向力 Fr=Ft·tanα；力的方向按轴位中心连线与
  啮合方向合成（外/内啮合径向反向，两体严格等大反向）。
- **轴承反力与余量**：安装面横向力作为轴上外载荷，两支点按刚体静力学求反力；
  给出每个轴承反力、利用率 R/Cr、安全余量 Cr/R 与 L10h 球轴承寿命；
  全列汇总峰值反力与最小余量，末端输出功率与总损失。
- **故障定位**：分支比例之和不为 1（**分支不闭合**）、两轴承支点重合
  （**载荷无法平衡**，诊断同时列出该轴上所有受影响的啮合）、安装面/轴承越出
  轴长或间距小于最小值、轴承超载、安装面悬于跨距外（悬臂告警）等，诊断条点击
  即滚动高亮对应轴卡、相关啮合卡。
- **轴系侧视图与拖动**：SVG 分层绘制轴体/标尺、力箭头（齿轮合力向上橙色、
  轴承反力向下蓝色）与可拖动的安装面/轴承；**拖动时力箭头与计算结果同步**
  （防抖重算，不中断拖拽）。**双击安装面/轴承锁定**已确定的位置。
- **布置搜索**：在轴长、最小间距与每元素可调范围（±mm）内枚举未锁定安装面与
  轴承的栅格位置，按 **超限数 → 最小余量（大优先）→ 峰值反力 → 改动量** 排序；
  候选可一键「采用并更新布置」，随后另存工况版本（同名版本号递增）。

## 热平衡工况

「热平衡」页以**一段连续运行或启停循环**为独立工况对象（`thermal.py` +
`/api/thermal/*`，版本存 SQLite 表 `thermal_cases`；不改写源轮系与源载荷版本）。

- **冻结来源**：点「从载荷版本建立草稿」选择一个或多个已保存的载荷工况版本
  （可勾选「同时内联当前载荷草稿」），后端对每个来源跑载荷分析并**冻结各级
  啮合功率损失、名义效率、各轴/轴承转速与径向载荷、持续时间**；冻结结果随版本
  保存，来源载荷或源轮系之后变化**只标记过期**，可一键「重新冻结来源」
  （保留时段编排与热参数，失效运行段被移除）。
- **时段编排**：运行段选择冻结来源并给载荷/转速比例与段环境温度（启停循环在
  段上缩放来源）；停机段全部热源为 0、只散热。各段首尾相接，总时长自动汇总。
- **热网络参数**：环境/初始温度、报告时间步（内部按稳定性自动细分）；油品牌号
  （ISO VG 68~320 的 40/100°C 黏温折线段，可自定义）、油量/密度/比热容决定
  油池热容量，允许黏度区间与效率黏敏度；齿轮节点（热容量 kJ/K、到油池热阻
  K/kW、搅油系数）与每个轴承节点（热容量、热阻、SKF M0/M1 摩擦模型的 f0/f1
  与节圆 dm）按冻结结果生成默认值；油→箱热阻、箱体热容量、**散热面积**、
  自然对流/风扇热阻（按面积倍乘电导）。
- **黏温曲线**：预置 ISO VG 68~320 的 40/100°C 折线段，也可在折点表中
  **自定义任意温度点/黏度**（至少 2 点，按温度升序，log10 插值）；每次输入
  都原地更新当前曲线（数组引用不变，连续修改同一折点也可靠保存）并即时重算、
  重绘；编辑折点即标记为「自定义」，重新选择预置牌号恢复。曲线 SVG 实时回显
  并叠加当前游标油温点与允许黏度区间。
- **温度限与风扇**：齿轮/轴承/油温三条温度限；风扇支持自动（启停温度回差，
  箱体温度判定）/强制开/强制关，风扇耗功部分计入箱壁热源；最短启停周期用于
  频繁启停诊断。
- **时间步迭代**：后端显式推进集中参数星形网络（叶节点→油池→箱体→环境），
  叶节点解析消元后对油池/箱体解 2×2 后向欧拉方程组，**无条件稳定**；油温经
  黏温曲线反馈到啮合效率（黏度偏低油膜变差，η 不超过名义值）、轴承黏性摩擦
  与搅油损失。返回每条边的逐样本热流、各节点逐样本温度与 η 曲线。
- **浏览器联动**：SVG 热网络按游标时刻绘制节点温度（超温变红）与各边热流
  （线宽按 kW），点节点可联动高亮；温度时间轴支持**拖动时间游标**（只移动
  游标层、不整体重绘），绘制各节点温度曲线、油温虚线黏度曲线、温度限、运行/
  停机段背景；顶部「按方案/强制开/强制关」**开关风扇**即触发整段重算。
  问题条目或平衡段卡片点击即把游标跳到对应时刻。
- **问题定位**：累计超温时长与峰值（齿轮/轴承/油/箱体逐节点列出区间）、
  **油黏度越界**区间、各运行段末段温升速率判定**热平衡未收敛**、自动模式下
  短于最短周期的**风扇频繁启停**次数与区间。
- **方案搜索**：勾选「锁定现有散热条件」只在油品范围搜索；否则在
  油品 × 散热片面积 × 风扇启停温度栅格上枚举。**所有候选统一依次比较
  超限时长 → 峰值温度 → 能耗 → 改动量排序，再按数量截断**；不按错误数额外
  排序，也不为当前配置置顶或补位（它若进入前 N 名仅显示「（当前）」，否则
  随其他候选一起被截断）。选中方案
  「采用并另存版本」——版本含**来源快照（冻结载荷与源轮系）、时间步设置与
  全部逐样本温度/黏度/η/热流曲线**（存 solution 列）。
- **草稿持久化与过期标记**：草稿（spec + frozen）编辑时防抖**写入服务端**
  `thermal_drafts` 表（本地 localStorage 仅作离线后备），换浏览器或清理站点
  数据后点「↻ 重载草稿」即可恢复。过期判定基于**前后端同一份规范指纹**
  （紧凑排序 JSON、标量归一化，逐字节一致）：已保存载荷版本仅在当前项目轮系
  与其快照实际不同时才标记过期，内联草稿还要载荷参数也变化才标记。

## 扭转振动工况

「扭振」页以**一次转速扫描**为独立版本（`torsional.py` + `/api/torsional/*`，
版本存 SQLite 表 `torsional_cases`、草稿存 `torsional_drafts`；不改写源轮系与源载荷版本）。

- **冻结与流转**：点「从载荷版本建立草稿」（可勾选「同时内联当前载荷草稿」），后端跑
  载荷分析并**冻结动力路径、各轴转速比与平均转矩**，按齿坯几何估算各轴转动惯量、
  啮合扭转刚度/阻尼，自动布置驱动端与负载端联轴器；随后填写各轴惯量，啮合/联轴器/
  负载端的扭转刚度与阻尼，设置输入转速范围、扫速步长与驱动端或负载端的激励阶次
  （可多阶次）。草稿防抖写入服务端，换浏览器可「↻ 重载草稿」。源轮系或源载荷变化
  **只标记过期**，版本下拉显示「⚠过期」，可「重新冻结来源」（保留仍存在轴/啮合的参数）。
- **力学模型**：集中参数扭振系统，惯量/刚度在各轴本地录入，组装时按精确转速比
  统一折算到输入轴（q̃=rθ；外啮合带方向号、内啮合同向）。纯 Python 求解
  Cholesky+Jacobi 广义特征值（含一个 ω=0 刚体模态），模态阻尼比 ζ=φᵀCφ/(2ω)；
  每个转速样本对每个阶次复高斯消元求频响，多阶次动态转矩按平方和开根合成，
  放大系数 =（平均+动态）/平均。共振转速附近自动**加密采样**避免漏掉窄峰。
- **Campbell 联动**：SVG 绘固有频率横线（欠阻尼红色虚线）、阶次激励斜线、穿越点
  与危险共振带（红底）、各啮合动态转矩超限条；点模态条目标注振型并高亮对应横线；
  **拖动红色转速游标**同步更新轴系扭转动画（各盘红弧＝扭振角幅与相位、弹簧按
  动态转矩变红）与读数：各轴幅/相位、各啮合动态/平均/总转矩与放大系数、激励频率，
  靠近穿越点时读数变红。点击诊断条目可跳到对应转速/模态。
- **避振搜索**：双击轴卡或弹簧卡可**锁定**；搜索只在**未锁定轴**上附加飞轮
  （惯量直接并入该轴）、对**未锁定联轴器**按刚度/阻尼倍率枚举，锁定部件绝不改动。
  候选统一按 **危险共振区数 → 最大动态转矩 → 附加惯量 → 改动量** 排序。
  「采用并另存版本」等待整段重算后，把输入、扫描结果与全部曲线冻结进版本。

## 诊断项

模数不合、压力角不一致、中心距冲突（默认容差 0.05 mm，可调）、内齿圈小于小齿轮、
重复约束（同一对轴两处啮合）、自啮合、转向/传动比矛盾、同轴错位、未连入动力链等。
点击诊断条目可定位到对应对象。

## 配齿搜索

1. 在轴属性里「锁定轴位」、齿轮属性里「锁定」不参与替换的部件；
2. 在「配齿搜索」填目标总传动比（分数，如 `1/4` 或 `-5/12`，不带负号只比绝对值）、
   允许误差 %、齿数范围、可用模数；
3. 候选按 **比值误差 → 非锁轴最大位移 → 最大齿数 → 中心距残差** 排序。
   每个候选列出被替换齿轮的旧/新齿数与模数、轴位位移、中心距偏差与循环倍数，
   在 SVG 上以蓝色新节圆 + 红色旧节圆虚线叠加；可用「逐级播放 / 连续旋转」
   检查动力传递后再「采用」。

## 操作

- 放轴/齿轮：空白处单击放轴；单击无齿轮的轴自动装齿轮，双击轴可继续加装齿轮；拖动轴移动。
- 建啮合：模式切到「建啮合」，从一只齿轮拖到另一只。
- 定同轴：模式切到「定同轴」，从一根轴拖到另一根。
- 滚轮缩放，空白处拖动平移；Delete 删除所选对象；单击诊断项定位。
