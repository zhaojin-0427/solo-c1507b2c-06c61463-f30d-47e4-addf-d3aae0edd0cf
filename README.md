# 轮系配齿台（Gear Train Workbench）

供钟表维修与机械模型制作推演复合齿轮列的本地工具：在 SVG 画布上放轴、装齿轮、
连啮合/同轴，实时传播转速与方向，计算总传动比、各轴转数与整列恢复初始啮合的循环；
并在锁定部分轴位/齿轮后按目标传动比搜索替换齿数与模数组合。

## 运行

```bash
pip install flask
python app.py
```

浏览器打开 <http://127.0.0.1:5000> 。数据保存在同目录 `geartrain.db`（SQLite），
画布自动保存；方案（备选）与基线也存库。

## 建模规则

- 齿轮参数：齿数 z、模数 m、压力角（默认 20°）、内齿圈标记；节圆半径 r′ = m·z/2。
- 外啮合中心距 = m(z₁+z₂)/2，相邻轴转向相反；
  内啮合中心距 = m|z圈−z轮|/2，转向相同。
- 同一根轴上的所有齿轮同转速；**同轴关系**表示两根同心安装但转速独立的轴，
  建立时未锁定轴会自动吸附同心。
- 转速用精确分数（Python `fractions` / 前端 BigInt）传播，闭合轮系两条路径
  推得的转速会被比对：符号相反报「转向矛盾」，同号不等报「传动比矛盾」。
- 复位循环 L：所有齿轮在输入轴转过 L 转后同时回到初始齿相位，
  即对每个 z·n 求分母的 LCM。

## 诊断项

模数不合、压力角不一致、中心距冲突（默认容差 0.05 mm，可调）、内齿圈小于小齿轮、
重复约束（同一对轴两处啮合）、自啮合、转向/传动比矛盾、同轴错位、未连入动力链等。
点击诊断条目可定位到对应对象。

## 配齿搜索

1. 在轴属性里「锁定轴位」、齿轮属性里「锁定」不参与替换的部件；
2. 在「配齿搜索」填目标总传动比（分数，如 `1/4` 或 `-5/12`，不带负号只比绝对值）、
   允许误差 %、齿数范围、可用模数；
3. 候选按 **比值误差 → 非锁轴最大位移 → 最大齿数 → 中心距残差** 排序。
   每个候选列出被替换齿轮的旧/新齿数与模数、轴位位移、中心距偏差与循环倍数，
   在 SVG 上以蓝色新节圆 + 红色旧节圆虚线叠加；可用「逐级播放 / 连续旋转」
   检查动力传递后再「采用」。

## 操作

- 放轴/齿轮：空白处单击放轴；单击无齿轮的轴自动装齿轮，双击轴可继续加装齿轮；拖动轴移动。
- 建啮合：模式切到「建啮合」，从一只齿轮拖到另一只。
- 定同轴：模式切到「定同轴」，从一根轴拖到另一根。
- 滚轮缩放，空白处拖动平移；Delete 删除所选对象；单击诊断项定位。
